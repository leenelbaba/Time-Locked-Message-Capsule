⏳ Time-Locked Message Capsule

tlock timelock encryption over the drand beacon. Nobody — including this server — holds a key that opens a capsule early.

Create a capsule

Works with any service that accepts a webhook (Slack/Discord/Teams incoming webhooks, Zapier, Make, IFTTT → email/SMS). The notification contains a link, never the message itself. Recipients are labels only — anyone with the link can read the capsule once it unlocks.

⚠️ Irreversible. Once sealed, nobody — including you and this server's admin — can open the capsule until the chosen drand round is published. No cancel, no edit, no early unlock.
